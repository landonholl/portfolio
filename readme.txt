# landonholland.com

This repository contains the source code for my personal portfolio website:  
https://landonholland.com

The site showcases my work, technical background, and areas of focus as a software engineer and game developer.

---

## Overview

This portfolio is designed to be a fast, modern, and visually polished single-page application. It highlights:

- Software and full-stack web development experience
- Game development and real-time systems work
- Operating systems, low-level programming, and systems concepts
- Selected projects, tools, and technical interests

The site is intended for recruiters, collaborators, and anyone interested in my work.

---

## Tech Stack

- **Frontend:** React, Vite, JavaScript / TypeScript
- **Styling:** CSS (custom, performance-focused)
- **Build Tooling:** Vite
- **Hosting:** AWS S3 (static site hosting)
- **Performance & SEO:** Optimized asset delivery, metadata, sitemap, and search indexing

The production build outputs static assets suitable for deployment to S3 or any static hosting provider.

## Deployment

The site is deployed as a static build to AWS S3 and served over HTTPS.
Supporting files such as robots.txt and sitemap.xml are included to enable proper search engine indexing.
